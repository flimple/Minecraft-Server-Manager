# Minecraft Server Manager (Global)

## About

Minecraft server management has been a real challenge to set up manually for me. So I decided to make this project to manage all possible servers and scenarios I would need.

### Planned Features

I plan to include multi server management, multi server hosting, server version updating along with its resource packs and mods (or migrating in another word), status checker for all servers, the ability to add apis for starting and stopping the servers, the ability to include vpns or domains for the hosting and secure access/ relay access.

### Work Plan

Currently the script shall only feature multi server management and a single server to be hosted while switching between which one is hosted. After that I will work towards adding mod management and auto modpack creation and installation. Then I will focus on the multi server hosting if possible, that solely depends on the support this project receives once it goes public.
